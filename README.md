# RobotPathCraft

Desktop-приложение на Python для проектирования траекторий мехатронных систем.

## Возможности

- Загрузка карт: `PNG/JPG`, `JSON`, `CSV`
- Расчёт траектории алгоритмами `A*` и `RRT`
- Сглаживание пути (shortcutting)
- Визуализация карты, старт/цели, дерева RRT и маршрута
- Текстовый отчёт с метриками и рекомендациями
- Сохранение изображения и сохранение/загрузка сеанса в JSON

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Форматы карт

- `PNG/JPG`: тёмные пиксели считаются препятствиями (настраиваемый порог)
- `JSON`:

```json
{
	"width": 100,
	"height": 100,
	"obstacles": [
		[10, 20],
		[11, 20]
	],
	"start": [5, 5],
	"goal": [90, 90]
}
```

- `CSV`: матрица `0/1`, где `1` означает препятствие
